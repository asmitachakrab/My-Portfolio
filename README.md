# My Portfolio

This is my personal portfolio, built from scratch using HTML, CSS, and scroll animations with AOS. It features my projects, resume, skills, projects and contact information — all styled with a minimalist pastel aesthetic. 🌸✨

## 🔧 Built With
- HTML5 & CSS3
- Font Awesome
- AOS (Animate on Scroll Library)

Projects

SmartSOS

SmartSOS is a portable, IoT-based emergency alert system designed to enhance personal safety through real-time location tracking, voice command detection, and an SOS button. Built using GPS, GSM, and microcontroller technology, the system enables users—especially in vulnerable situations—to instantly send distress signals with their coordinates to preconfigured emergency contacts. It’s ideal for students, elderly individuals, and those in isolated areas. This project demonstrates practical integration of embedded systems, wireless communication, and safety-first design thinking.

RealityCheck.AI

RealityCheck.AI is a GenAI-powered agent designed to verify the authenticity of internal corporate claims using Few-shot Prompting, RAG (Retrieval Augmented Generation), and Function Calling. Instead of acting like a chatbot, it operates as a robust backend agent that cross-checks claims against synthetic documentation stored in a vector database. It’s ideal for internal fact-checking in knowledge-driven organizations, reducing misinformation and enhancing decision-making. The project highlights practical use of LLM orchestration and agent design for enterprise tasks.

Sentiment Analysis System for Movie Reviews

This project uses machine learning and natural language processing (NLP) to classify the sentiment of movie reviews as positive or negative. Using a Streamlit User Interface, it processes textual data using techniques like tokenization, TF-IDF vectorization, and applies classifiers such as Logistic Regression or SVM to predict sentiment with high accuracy. The system can be adapted to real-world feedback analysis, including product reviews or customer testimonials. It showcases the application of NLP pipelines and model evaluation in sentiment mining tasks.
